# 📊 HR Analytics Dashboard

## 📌 Project Overview
This project is an interactive HR Analytics Dashboard built using Microsoft Power BI. It helps HR teams analyze employee attrition, workforce demographics, job satisfaction, salary trends, and overall workforce performance through interactive visualizations.

---

## 🚀 Dashboard Features

- 📌 Total Employees
- 📌 Attrition Rate
- 📌 Average Salary
- 📌 Average Tenure
- 📌 Performance Rate
- 📌 Average Performance Score
- 📌 Department-wise Performance
- 📌 Monthly Income by Job Role
- 📌 Gender Diversity Analysis
- 📌 Age Group Distribution
- 📌 Job Satisfaction Heatmap
- 📌 Interactive Filters

## 📈 Key Insights

- Total Employees: **1470**
- Attrition Rate: **16.12%**
- Average Salary: **6.50K**
- Average Tenure: **7.01 Years**
- Performance Rate: **39.52%**
- Average Performance Score: **3.15**
- R&D department has the highest number of employees.
- The 26–35 age group has the largest workforce.
- Interactive filters enable detailed HR analysis.
